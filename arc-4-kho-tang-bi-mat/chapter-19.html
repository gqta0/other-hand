Chapter 19: Kiếm Pháp Biến Hình

📖 XML Dynamic SQL ⏱️ 30 phút

Phần 1: Sự Bất Lực Của Tĩnh Pháp (5 phút)

Người kể chuyện

Lâm Tuấn đang hì hục viết hàng chục câu lệnh `@Select` trong Java Interface. `findByName(String name)` `findByAge(Integer age)` `findByNameAndAge(String name, Integer age)` ... Mồ hôi vã ra như tắm. Sư Tỷ Linh đi ngang qua, lắc đầu ngao ngán.

Sư Tỷ Linh

Sư đệ, nếu ta thêm một tiêu chí lọc nữa là `level`, ngươi sẽ phải viết thêm bao nhiêu hàm nữa? Cấp số nhân đấy! Đã đến lúc ngươi bỏ tấm bản đồ tĩnh (Annotation) xuống và cầm lấy cuộn giấy da cổ xưa (XML Mapper). Ở đó, ta có thể tri triển Dynamic SQL - Kiếm pháp biến hình.

Lâm Tuấn

XML ư? Nhưng nó dài dòng lắm!

Sư Tỷ Linh

Dài nhưng "chất". Chỉ một câu lệnh XML có thể thay thế cho cả trăm hàm Java của ngươi. Hãy xem đây!

Phần 2: Thẻ IF và WHERE (Quyết Định Luồng Kiếm) (10 phút)

Sư Tỷ Linh

Trong file XML, ta định nghĩa một câu lệnh `select` với id là `searchDisciples`. `<select id="searchDisciples" resultType="Disciple">` ` SELECT * FROM disciples` ` <where>` ` <if test="name != null"> AND name like #{name} </if>` ` <if test="age != null"> AND age = #{age} </if>` ` </where>` `</select>`

Lâm Tuấn

Ồ! Nếu `name` truyền vào là null, đoạn SQL `AND name like` sẽ biến mất?

Sư Tỷ Linh

Chính xác. Và cái thẻ `` cực kỳ thông minh. Nếu bên trong nó không có điều kiện nào (cả name và age đều null), nó sẽ không sinh ra chữ `WHERE`. Nếu chỉ có `age`, nó sẽ tự động cắt bỏ chữ `AND` thừa ở đầu câu. Nó giúp ngươi tránh lỗi cú pháp SQL ngớ ngẩn kiểu `WHERE AND age = 10`.

Lâm Tuấn

Thật vi diệu! Như vậy đệ tử chỉ cần một hàm duy nhất: `List searchDisciples(DiscipleSearchCriteria criteria);`

Phần 3: Thẻ CHOOSE, SET và FOREACH (Biến Hóa Khôn Lường) (10 phút)

Sư Tỷ Linh

Chưa hết đâu. Đôi khi ngươi muốn dùng logic "Nếu... thì... Nếu không thì..." (Switch-Case). Hãy dùng ``, ``, ``. Ví dụ: Nếu có `id` thì tìm theo id. Nếu không có id mà có `name` thì tìm theo name. Nếu không có cả hai thì tìm những kẻ đang active.

Lâm Tuấn

Còn khi Update thì sao ạ? Đệ tử chỉ muốn update những trường nào khác null thôi (Dynamic Update).

Sư Tỷ Linh

Dùng thẻ ``. `UPDATE disciples` `<set>` ` <if test="name != null"> name = #{name}, </if>` ` <if test="age != null"> age = #{age}, </if>` `</set>` `WHERE id = #{id}` Thẻ `` sẽ tự động xóa dấu phẩy thừa ở cuối.

Sư Phụ Cao Nhân

(Xuất hiện) Sư Tỷ nói đúng, nhưng còn một chiêu thức quan trọng nhất: Bulk Operation. Làm sao để xóa 1000 đệ tử cùng lúc? Đừng gọi hàm delete 1000 lần! Hãy dùng thẻ ``. `DELETE FROM disciples WHERE id IN` `<foreach item="id" collection="listIds" open="(" separator="," close=")">` ` #{id}` `</foreach>` Nó sẽ sinh ra câu lệnh: `IN (1, 2, 3, 4...)`. Nhanh hơn gấp bội phần.

Phần 4: Tổng Kết (5 phút)

Người kể chuyện

Lâm Tuấn ngẩn người thán phục. Dynamic SQL giống như nước, có thể len lỏi vào mọi ngóc ngách của yêu cầu nghiệp vụ. Với file XML Mapper, code Java trở nên sạch sẽ vô cùng, chỉ còn Interfaces. Mọi sự phức tạp của SQL được giấu kín bên trong hang động XML.

Sư Tỷ Linh

Hành trang đã đủ. Ngươi đã có bản đồ (Mapper), biết câu thần chú (SQL Basics), biết ghép nối dữ liệu (ResultMap), và biết biến hóa chiêu thức (Dynamic SQL). Ngày mai, Sư Phụ sẽ đưa ngươi vào trận địa thực tế cuối cùng của Arc này: Xây dựng hệ thống "Quản Lý Nhiệm Vụ Đệ Tử" hoàn chỉnh, kết hợp tất cả những gì đã học.

📚 Thuật Ngữ Chương Này

  • Dynamic SQL Khả năng tạo ra câu lệnh SQL thay đổi động dựa trên tham số đầu vào (ví dụ: null check).
  • <where> Thẻ thông minh tự động thêm/xóa từ khóa WHERE và AND/OR thừa ở đầu.
  • <set> Thẻ thông minh cho câu UPDATE, tự động xóa dấu phẩy thừa ở cuối.
  • <foreach> Thẻ lặp dùng cho các toán tử IN (...) hoặc Batch Insert.

💼 Câu Hỏi Phỏng Vấn

  1. Dynamic SQL giúp giải quyết vấn đề gì? (Tránh cộng chuỗi thủ công, xử lý optional parameters).
  2. Sự khác biệt giữa <if> và <choose>? (if là check độc lập, choose là if-else độc quyền).
  3. Thẻ <where> xử lý các từ khóa AND/OR như thế nào? (Tự động loại bỏ AND/OR nếu nó nằm ở đầu nội dung bên trong).
  4. Làm sao để thực hiện Bulk Insert với MyBatis? (Dùng <foreach> trong câu INSERT VALUES).
