Phần 1: Người Giữ Kho (5 phút)

Người kể chuyện

Rời khỏi Tàng Kinh Các với kiến thức phòng thủ vững chắc, Lâm Tuấn được dẫn đến một ngọn núi phía sau tông môn gọi là "Dữ Liệu Sơn". Tại chân núi, một hang động lớn phát ra ánh sáng lung linh, bên trên đề ba chữ: "Kho Tàng Bí Mật" (Database). Đứng trấn giữ cửa hang là một nữ tử xinh đẹp, khí chất thanh cao, tay cầm một cuốn bản đồ da cổ kính.

Sư Tỷ Linh

Chào sư đệ. Ta là Linh, người cai quản dữ liệu của Spring Tông. Sư Phụ nói ngươi muốn học cách lấy báu vật (Data) từ trong kho này ra một cách tinh tế nhất?

Lâm Tuấn

Chào Sư Tỷ. Đệ tử trước giờ dùng JDBC, phải tự tay đục đá (viết Connection, PreparedStatement, ResultSet) rất vất vả. Nghe nói môn phái có tuyệt kỹ MyBatis giúp công việc này nhẹ nhàng hơn?

Sư Tỷ Linh

Đúng vậy. MyBatis (hay còn gọi là Tiên Pháp Mai Ba Tít) là một "Persistence Framework". Khác với Hibernate (một pháp môn khác tự động hóa hoàn toàn), MyBatis trao cho ngươi quyền kiểm soát tuyệt đối câu thần chú (SQL). Nó không tự ý sinh ra câu lệnh lạ, mà chỉ giúp ngươi ánh xạ kết quả từ SQL vào Object Java. Chúng ta gọi đó là SQL Mapping.

Phần 2: Tấm Bản Đồ (Mapper Interface) (10 phút)

Sư Tỷ Linh

Để vào kho, ngươi không cần mang theo búa rìu (JDBC Code) nữa. Ngươi chỉ cần vẽ một tấm bản đồ, gọi là Mapper Interface. MyBatis sẽ nhìn vào bản đồ đó và tự động tạo ra người thợ đào kho báu cho ngươi (Proxy Object).

Sư Tỷ Linh

Đầu tiên, hãy tạo một Interface và gắn huy hiệu `@Mapper` lên đó. Ví dụ: `@Mapper` `public interface DiscipleMapper { ... }` Việc gắn `@Mapper` giúp Spring tự động nhận diện và tạo Bean cho nó (scan). Ngươi không cần `@Repository` nữa.

Lâm Tuấn

Đơn giản vậy sao? Vậy làm sao để định nghĩa câu lệnh SQL?

Sư Tỷ Linh

Có hai cách. Cách thứ nhất là dùng Annotation ngay trên hàm. `@Select("SELECT * FROM disciples WHERE id = #{id}")` `Disciple findById(Long id);` Cách này nhanh, gọn, dùng cho câu lệnh đơn giản.

Sư Tỷ Linh

Cách thứ hai là dùng XML Configuration. Ngươi viết SQL trong một file XML riêng biệt. Cách này mạnh mẽ hơn, giúp tách biệt code Java và SQL, rất hữu dụng khi câu lệnh dài và phức tạp (Dynamic SQL).

Phần 3: Cấu Hình Kết Nối (5 phút)

Lâm Tuấn

Nhưng Sư Tỷ, làm sao MyBatis biết kho báu (Database) nằm ở đâu mà đào?

Sư Tỷ Linh

Ngươi cần khai báo thông tin kết nối trong `application.properties`. `spring.datasource.url=jdbc:mysql://localhost:3306/spring_sect` `spring.datasource.username=root` `spring.datasource.password=secret` Và quan trọng là driver: `spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver`.

Sư Tỷ Linh

Ngoài ra, để MyBatis tìm thấy các file XML (nếu dùng cách 2), ngươi cần thêm: `mybatis.mapper-locations=classpath:mapper/*.xml` Và để viết ngắn gọn trong XML (không cần package name dài dòng), ta dùng: `mybatis.type-aliases-package=com.springsect.model`

Lâm Tuấn

Đệ tử hiểu rồi. 1. Config Datasource (Địa chỉ kho). 2. Tạo Mapper Interface (Bản đồ). 3. Viết SQL (Thần chú). 4. Inject Mapper vào Service và dùng.

Phần 4: Tổng Kết (5 phút)

Người kể chuyện

Lâm Tuấn nhận lấy cuộn giấy da `@Mapper` từ tay Sư Tỷ Linh. Anh cảm thấy nhẹ nhõm hơn hẳn so với việc cầm cái búa tạ JDBC nặng trịch. MyBatis giống như một người trợ lý đắc lực: Bạn chỉ cần nói muốn gì (SQL) và muốn nhận lại gì (Object), còn việc chuyển đổi (Resultset Parsing) để nó lo.

Sư Tỷ Linh

Hôm nay ngươi đã có bản đồ. Ngày mai, chúng ta sẽ bắt đầu học những câu thần chú cơ bản để lấy đồ vật ra, cất đồ vật vào. Hãy chuẩn bị tinh thần học về CRUD Operations với MyBatis.

📚 Thuật Ngữ Chương Này

  • MyBatis Persistence Framework giúp ánh xạ SQL vào Java Object. Kiểm soát SQL tốt hơn JPA.
  • @Mapper Annotation đánh dấu Interface lầ MyBatis Mapper. Spring sẽ tạo Proxy implementation cho nó.
  • ORM (Object Relational Mapping) Kỹ thuật ánh xạ dữ liệu quan hệ (bảng) sang đối tượng (class). MyBatis là "Semi-ORM".
  • Datasource Cấu hình nguồn dữ liệu (URL, User, Pass) để kết nối Database.

💼 Câu Hỏi Phỏng Vấn

  1. Sự khác biệt chính giữa MyBatis và Hibernate/JPA? (SQL Control vs Full Automation).
  2. @Mapper và @Repository khác nhau thế nào trong ngữ cảnh MyBatis?
  3. Làm sao để cấu hình MyBatis tìm thấy file XML mapper? (mybatis.mapper-locations).
  4. `#{param}` và `${param}` trong MyBatis khác nhau ra sao? (Prepared Statement vs String Substitution - Cẩn thận SQL Injection!).
