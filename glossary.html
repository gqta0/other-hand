Spring Core

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
IoC Container Linh Khí Tụ Trung tâm quản lý tất cả Bean, chịu trách nhiệm tạo, quản lý vòng đời và inject dependency
Dependency Injection Linh Lực Quán Nhập Container tự động cung cấp dependency cho Bean thay vì Bean tự tạo
Bean Linh Đan Đối tượng được quản lý bởi Spring Container
@Component Phù Chú Linh Khí Annotation gốc đánh dấu class là Bean
@Service Phù Chú Dịch Vụ Đánh dấu class chứa business logic
@Repository Phù Chú Kho Tàng Đánh dấu class truy cập database, có exception translation
@Autowired Tự Động Kết Nối Yêu cầu Container inject dependency
Singleton Độc Nhất Vô Nhị Scope mặc định, chỉ một instance trong Container
Prototype Đa Bản Sao Tạo instance mới mỗi lần yêu cầu
@PostConstruct Sau Khi Thành Đan Phương thức gọi sau khi DI hoàn tất
@PreDestroy Trước Khi Tiêu Tan Phương thức gọi trước khi Bean bị hủy
🌐

Spring Web MVC

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
DispatcherServlet Truyền Tống Linh Đồng Front Controller xử lý tất cả HTTP request
@RequestMapping Phù Chú Lộ Trình Ánh xạ URL đến phương thức Controller
@Controller Phù Chú Điều Khiển Đánh dấu class xử lý HTTP request
@RestController Điều Khiển Thuần Dữ Liệu Controller + ResponseBody, trả JSON/XML
@PathVariable Biến Đường Dẫn Lấy giá trị từ URL path
@RequestBody Thân Yêu Cầu Deserialize HTTP body thành Java object
ResponseEntity Thực Thể Phản Hồi Wrapper cho HTTP response với status và headers
Model Linh Khí Mô Hình Container chứa dữ liệu truyền từ Controller sang View
View Huyễn Cảnh Template engine render dữ liệu thành HTML
🛡️

Spring Security

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
Authentication Xác Thực Thân Phận Xác minh danh tính: Bạn là ai?
Authorization Phân Quyền Hạn Xác định quyền: Bạn được làm gì?
JWT Token Linh Bài Thông Hành Chuỗi mã hóa chứa thông tin xác thực
Security Filter Chain Chuỗi Phòng Hộ Pháp Trận Chuỗi filter xử lý security request
@Secured Phù Chú Phòng Hộ Bảo vệ method theo role
🏛️

MyBatis

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
Mapper Bản Đồ Kho Tàng Interface ánh xạ SQL đến phương thức Java
SQL Thần Chú Truy Vấn Ngôn ngữ truy vấn database
ResultMap Bản Đồ Kết Quả Ánh xạ column database sang field Java
Dynamic SQL Thần Chú Biến Hóa SQL thay đổi theo điều kiện runtime

Transaction

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
@Transactional Phù Chú Giao Dịch Đảm bảo tất cả thao tác thành công hoặc rollback toàn bộ
ACID Tứ Đại Quy Tắc Atomicity, Consistency, Isolation, Durability
Propagation Truyền Dẫn Pháp Tắc Cách transaction lan truyền giữa các method
Isolation Cô Lập Pháp Tắc Mức độ cô lập giữa các transaction
✨

AOP - Aspect Oriented Programming

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
Aspect Khía Cạnh Pháp Module chứa cross-cutting concerns
@Before Phù Chú Tiền Trận Advice chạy trước method
@After Phù Chú Hậu Trận Advice chạy sau method
@Around Phù Chú Bao Vây Advice bao quanh method execution
JoinPoint Điểm Giao Hội Điểm có thể áp dụng aspect
Pointcut Điểm Cắt Expression xác định JoinPoint nào được áp dụng
@AfterReturning Phù Chú Hồi Đáp Advice chạy sau khi method trả về thành công
@AfterThrowing Phù Chú Ngoại Lệ Advice chạy khi method ném ra Exception
ProceedingJoinPoint Lệnh Bài Tiếp Diễn Tham số của @Around, dùng để gọi method gốc (proceed)
Self-Invocation Tự Gọi Chính Mình Vấn đề Method A gọi Method B cùng class -> AOP không hoạt động
🧪

Testing

Thuật Ngữ Ẩn Dụ Tu Tiên Mô Tả
JUnit Thử Nghiệm Đơn Vị Framework testing cho Java
Mockito Huyễn Thuật Giả Lập Framework tạo mock object
@MockBean Linh Đan Giả Tạo mock Bean trong Spring context
@SpringBootTest Đại Thử Nghiệm Load toàn bộ Spring context để test
@WebMvcTest Thử Nghiệm Tầng Web Test slice cho Controller layer
Assertions Lời Khẳng Định Các hàm kiểm tra kết quả test (assertEquals, assertTrue)
@BeforeEach / @AfterEach Chuẩn Bị / Dọn Dẹp Chạy trước và sau mỗi @Test method
@BeforeAll / @AfterAll Khai Mở / Đóng Màn Chạy 1 lần duy nhất cho cả class test (static)
@InjectMocks Tiêm Thuốc Hình Nhân Tạo object thật và inject các @Mock vào trong nó
TestContainers Hộp Thần Kỳ Thư viện chạy Database thật trong Docker khi test
Docker Thùng Chứa Nền tảng chạy ứng dụng trong container cô lập
